AI回复

是的，eutils.ncbi.nlm.nih.gov 是 NCBI 的 E-utilities API，可以用来搜索文献（主要是 PubMed 数据库中的生物医学文献）。

核心工具是 esearch（搜索）+ efetch/esummary（获取详情）。

基本搜索示例（PubMed 文献搜索）：

# 1. 搜索关键词，返回文献 PMID 列表
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=CRISPR+cancer&retmax=5"

# 2. 用返回的 PMID 获取摘要
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=pubmed&id=35961664&rettype=abstract"

# 3. 或获取结构化摘要（JSON）
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=35961664&retmode=json"

常用参数：

  • db=pubmed：指定 PubMed 文献库
  • term：搜索词，支持字段限定，如 cancer[Title] AND 2023[PDAT]
  • retmax：返回结果数量
  • retstart：分页偏移
  • retmode=json：返回 JSON 格式

其他相关文献型数据库：

  • db=pmc：PubMed Central 全文
  • db=pubmed：文献摘要/元数据

注意事项：

  • 建议加上 tool 和 email 参数标识自己（NCBI 要求批量使用时提供）
  • 限速：无 API key 约 3 次/秒，有 key 约 10 次/秒
  • 需要连续翻页时可用 usehistory=y 结合 query_key/WebEnv 避免重复传 term
